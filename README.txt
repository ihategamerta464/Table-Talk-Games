TABLE TALK ARCADE — TEXAS HOLD’EM + PLINKO

CodePen setup:
1. Create a new Pen at https://codepen.io/pen/
2. Paste index.html into the HTML panel.
3. Paste style.css into the CSS panel.
4. Paste script.js into the JS panel.

Both games use pretend chips only. Poker and Plinko use separate play-chip balances.
